Project 01

Oregon Traffic Analysis

Spatial-Temporal Congestion Patterns

Comprehensive analysis of INRIX probe vehicle sensor data along OR-99W Southbound, examining 33 road segments across Washington County, Oregon. Interactive visualizations reveal how congestion patterns emerge and propagate through space and time.

Key Features:

  • Hovmöller diagrams showing space-time evolution
  • Interactive cluster analysis by day and time
  • Congestion threshold comparison tool
  • 5-minute resolution across 33 segments
  • Spatial heterogeneity visualization

Project 02

Bayesian Traffic Model New

Dirichlet Process Mixture + HSGP

Sophisticated Bayesian model that automatically discovers traffic regimes without pre-labeling, combining Dirichlet Process mixtures with locally-periodic Gaussian Processes. Features computationally efficient HSGP approximation for real-time analysis.

Key Features:

  • Automatic regime detection (no labels needed)
  • Real-time parameter adjustment
  • 5 interactive visualization modes
  • Uncertainty quantification
  • Spectral density analysis
